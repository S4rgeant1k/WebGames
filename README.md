# WebGames — UPGRADER SIM

Браузерный **симулятор апгрейда скинов** в стиле upgrader-сайтов: ставишь предмет, выбираешь цель подороже и крутишь колесо шанса.

## 🎮 [Играть онлайн → s4rgeant1k.github.io/WebGames](https://s4rgeant1k.github.io/WebGames/)

> ⚠️ Это игра-симулятор. Все монеты и предметы виртуальные — их нельзя купить, продать или вывести. Реальные деньги не используются.
> Изображения и названия скинов © Valve Corporation (загружаются с CDN Steam). Фанатский проект, не связан с Valve.

## Что есть в игре

- 🎯 **Апгрейд** — до 6 предметов + монеты с баланса в одной ставке, кнопки x1.5 / x2 / x3 / x5 / x10, колесо с сектором шанса (5–95%), утешительный приз при проигрыше.
- 📦 **Кейсы** — 6 кейсов от ◆ 130 до ◆ 50 500 (вплоть до ножевого и снайперского с шансом на Dragon Lore), рулетка как на сайтах, до 5 кейсов сразу, шансы видны.
- 🛒 **Рынок** — 119 настоящих скинов CS2 с фото: от P250 | Sand Dune до AWP | Dragon Lore, M4A4 | Howl, ножей и перчаток. Цены примерно рыночные (1 ◆ ≈ 1 цент).
- 🎒 **Инвентарь** — продажа по одному, выборочно или всё сразу.
- 👤 **Профиль** — статистика, история, ежедневный бонус с серией, пособие, если всё проиграл.
- 🔐 **Честная игра (Provably Fair)** — результат = `sha256(серверный_сид:клиентский_сид:nonce)`, любую ставку можно перепроверить.
- 📱 Работает на телефоне, прогресс сохраняется в браузере, звуки генерируются кодом.

## ▶️ Как поиграть (проще всего)

1. Нажми на файл **`play.html`** в списке файлов выше.
2. Справа над кодом нажми кнопку **скачивания** (стрелка вниз, «Download raw file»).
3. Открой скачанный `play.html` двойным кликом — игра запустится в браузере.

Ничего устанавливать не нужно, работает без интернета. Прогресс сохраняется в браузере.

## Запуск для разработчиков

Нужен [Node.js](https://nodejs.org) (18+):

```bash
npm start        # локальный сервер на http://localhost:8080
npm install      # один раз, чтобы установить сборщик
npm run build    # пересобрать play.html после изменений в коде
```

Игра — это обычные статические файлы, поэтому её можно выложить на **GitHub Pages** (Settings → Pages → Deploy from branch) или любой хостинг.

## Тесты

```bash
npm test
```

Проверяют каталог, честность шансов (Монте-Карло), что стрелка колеса всегда попадает в нужную зону, баланс цен кейсов и SHA-256.

## Структура

```
index.html        — разметка страниц
css/style.css     — оформление
js/data.js        — редкости, кейсы, настройки экономики (CONFIG)
js/skins.js       — список скинов (генерируется scripts/gen-skins.py)
js/economy.js     — шансы, колесо, кейсы (чистая логика)
js/fair.js        — Provably Fair, SHA-256
js/art.js         — фото скинов из Steam + запасные SVG-силуэты
js/audio.js       — звуки (Web Audio)
js/state.js       — сохранение прогресса
js/main.js        — интерфейс
server.mjs        — локальный сервер
play.html         — вся игра одним файлом (собирается командой npm run build)
scripts/          — сборка play.html
tests/            — тесты
```

**Хочешь поменять баланс?** Стартовые деньги, бонус и возврат игроку (RTP) — в `js/data.js`.
**Добавить скин или поменять цену** — в списке `PICK` в `scripts/gen-skins.py`, затем:

```bash
curl -L -o /tmp/skins.json https://bymykel.github.io/CSGO-API/api/en/skins.json
python3 scripts/gen-skins.py /tmp/skins.json
npm run build
```
