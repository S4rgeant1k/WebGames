# PC BUILD SIM — симулятор сборки ПК в браузере (3D)

▶ **Играть прямо в браузере:** https://s4rgeant1k.github.io/WebGames/

Ничего скачивать и устанавливать не нужно. Работает на компьютере и на телефоне.
Игра вдохновлена PC Building Simulator. Модели, названия и интерфейс сделаны с нуля.

## Как играть

1. Откройте **📧 Почту** и возьмите заказ от клиента.
2. На столе появится компьютер клиента (или пустое место, если просят собрать новый ПК).
3. Задача заказа видна слева. Выполненные пункты подсвечиваются зелёным.
4. Сдайте заказ кнопкой **«Сдать заказ»**. Вы получите деньги и опыт, а с новым уровнем откроются новые детали.

### Управление
| Действие | Как сделать |
|---|---|
| Повернуть камеру | зажать мышь / палец и тянуть |
| Приблизить | колесо мыши / щипок двумя пальцами |
| Снять деталь | нажать на деталь в корпусе → «Снять» |
| Поставить деталь | выбрать деталь в инвентаре → нажать на **зелёный** слот в корпусе |
| Кабели питания | кнопка **🔌 Кабели** → нажать на жёлтые точки |
| Убрать пыль | кнопка **💨 Продувка** → нажимать на пыльные детали |
| Проверить ПК | **⏻ Включить**, после загрузки **📊 Тест** |

### Типы заказов
- **Сборка** — собрать ПК в рамках бюджета, чтобы он набрал нужные очки в тесте;
- **Апгрейд** — поставить более мощную видеокарту, процессор, память или SSD;
- **Ремонт** — найти и заменить сломанную деталь (ПК не включается, нет изображения…);
- **Чистка** — компьютер перегревается, нужно убрать пыль.

Есть режим **Песочница** (меню ☰ справа сверху): бесконечные деньги, открыты все детали.
Прогресс сохраняется в браузере автоматически.

## Для разработчика

```bash
npm install
npm run build   # собирает src/ → assets/game.js
npm start       # http://localhost:8080
npm test        # проверка игровой логики
```

- `src/parts.js` — каталог деталей (процессоры, платы, видеокарты и т. д.);
- `src/logic.js` — совместимость, установка, кабели, питание, тест производительности;
- `src/jobs.js` — генератор заказов;
- `src/scene.js` — 3D-мастерская на three.js;
- `src/screen.js` — экран монитора (BIOS, загрузка, рабочий стол);
- `src/main.js` — интерфейс и игровой процесс.

Готовый файл `assets/game.js` хранится в репозитории, чтобы игра работала на GitHub Pages без сборки.

Прошлая игра (симулятор апгрейдера скинов) осталась в истории репозитория (коммит `8e82bb9`).
