# PC BUILD SIM — 3D-симулятор компьютерной мастерской в браузере

▶ **Играть прямо в браузере:** https://s4rgeant1k.github.io/WebGames/

Ничего скачивать не нужно, игра работает на компьютере и на телефоне.
Её вдохновил PC Building Simulator, но модели, названия и код написаны с нуля.

## Как играть

Вы ходите по своей мастерской от первого лица.

1. **Компьютер мастерской** стоит у правой стены. На нём есть:
   - Почта с заказами (кнопки «Принять» и «Отклонить»);
   - Магазин деталей с корзиной;
   - список заказов, склад, статистика и настройки.
2. Компьютер принятого заказа привозят на **стеллаж** у левой стены. Подойдите к нему и поставьте ПК на верстак.
3. За **верстаком** можно:
   - снимать и ставить детали;
   - подключать кабели;
   - продувать пыль;
   - включать ПК.

   После загрузки нажмите «Монитор»: откроется система с **3DMark**, сведениями о системе и датчиками температуры.
4. Когда все пункты заказа отмечены зелёным, нажмите **«Сдать заказ»**. Вы получите деньги, опыт и репутацию (звёзды).
5. Можно собрать **свой ПК**: купите детали и поставьте корпус на пустой верстак. Готовый компьютер продаётся дороже стоимости деталей.
6. Когда письма закончатся, выйдите через **дверь**, чтобы закончить день. Утром придут новые заказы.

У каждого клиента свой, случайно собранный компьютер.
В каталоге почти 250 деталей с ценами в рублях:
- 48 процессоров и 56 материнских плат;
- 25 видеокарт и 28 блоков питания;
- 23 кулера и СЖО, 22 корпуса и другое.

Игра проверяет, совместимы ли детали:
- сокет процессора и тип памяти DDR4/DDR5;
- форм-фактор платы;
- длину видеокарты и высоту кулера;
- размер радиатора СЖО;
- мощность блока питания и разъём 12VHPWR.

### Управление
| Действие | Компьютер | Телефон |
|---|---|---|
| Ходить | W A S D (Shift — бег) | джойстик слева |
| Осмотреться | мышь | провести пальцем справа |
| Действие | E или клик | кнопка с рукой |
| Склад деталей | Tab | кнопка с коробкой |
| Назад / меню | Esc | кнопка ☰ |
| За верстаком | C — кабели, B — продувка, P — питание, M — монитор, R — камера | кнопки внизу |

Есть режим **Песочница**: бесконечные деньги и все детали открыты.
Прогресс сохраняется в браузере автоматически.

## Для разработчика

```bash
npm install
npm run build   # собирает src/ → assets/game.js
npm start       # http://localhost:8080
npm test        # проверка игровой логики
```

| Файл | Что внутри |
|---|---|
| `src/parts.js` | каталог деталей |
| `src/logic.js` | совместимость, установка, кабели, включение, 3DMark |
| `src/jobs.js` | генератор заказов и случайных ПК клиентов |
| `src/state.js` | состояние и сохранение |
| `src/scene.js` | 3D-мастерская: комната, ходьба, верстак, стеллаж (three.js) |
| `src/models.js` | 3D-модели деталей |
| `src/screen.js` | экран монитора на верстаке (BIOS, загрузка, тест) |
| `src/icons.js` | SVG-иконки интерфейса |
| `src/main.js` | интерфейс и игровой процесс |

Готовый файл `assets/game.js` хранится в репозитории: так игра работает на GitHub Pages без сборки.
